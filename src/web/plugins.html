Built in

These are not plugins — they are already part of the room. Listed so you know they are there, and so you can see which ones still need a connection before they will work.

Skills

Instructions you have written, uploaded once. A skill tells a model how you want something done — a review checklist, a house style, a procedure — and it is handed over in your words, not summarised. Upload a .md file, or a .zip of a skill folder with a SKILL.md in it.

Endpoints

An HTTP call you describe once, which any agent can then make. The description is what a model reads to decide whether to reach for it, so vague ones get called at the wrong moments.
